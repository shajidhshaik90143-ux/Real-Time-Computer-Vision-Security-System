# 👁️ Real-Time Computer Vision Security System

An AI-powered real-time security monitoring system built using Python, OpenCV, YOLO, Streamlit and SQLite.

## Features

- Real-time webcam monitoring
- Person detection
- Motion detection
- Face detection
- Basic registered-face matching
- Unknown face detection
- Security event logging
- Evidence image capture
- SQLite database
- Interactive dashboard
- Event history
- Analytics
- CSV report export

## Technology Stack

- Python
- OpenCV
- YOLO
- Streamlit
- SQLite
- NumPy
- Pandas
- Plotly
